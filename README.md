StockLedger 📦

StockLedger is a modern inventory and sales management system built to help small businesses track products, manage stock levels, record sales, monitor profits, and generate business reports in real-time.

Designed with a clean dark-themed UI, StockLedger combines inventory management, point-of-sale functionality, analytics, and reporting into a single platform.

🚀 Live Demo

Application: https://stockledger-snowy.vercel.app/
